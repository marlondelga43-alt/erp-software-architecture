# 10. Glosario

| Término | Definición |
|---|---|
| Producto | Bien o insumo que la empresa compra a proveedores para su operación o reventa. |
| Proveedor | Entidad externa que suministra productos a la empresa. |
| Orden de Compra | Documento formal que solicita a un proveedor el suministro de productos en determinadas cantidades y condiciones. |
| Recepción de Mercancía | Proceso de confirmar físicamente la llegada de los productos solicitados en una orden de compra. |
| Stock | Cantidad disponible de un producto en el inventario de la empresa. |
| SPA | Single-Page Application, aplicación web que carga una única página HTML y actualiza el contenido dinámicamente. |
